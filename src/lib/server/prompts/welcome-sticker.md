# Welcome Sticker Prompt

{{characterName}} waving enthusiastically and pointing down with a friendly smile.

A speech bubble says: "WELCOME!" in emphasized style then "Make a Sticker Below" in more normal font

## Scene Details

- The character should have an excited, welcoming expression
- One hand waving in greeting
- Other hand pointing downward (toward where the prompt input would be)
- Warm, friendly body language
- The speech bubble should be really large (maybe even covering the character some) so that it can be read even when the images is at a small size
