# Character Generation Prompt

Following the style of the character in the first image, make another character of the same style that represents the person in the second image. The resulting character image should be a full-body representation of the person in the second image.

## Style Requirements

- Die-cut sticker comic illustration
- Bold black outlines
- Vibrant saturated colors with clean cel-shading
- Clean white border outline
- Subtle drop shadow
- Square 1:1 aspect ratio
- The background MUST be bright chroma key green (#00FF00)

Create a friendly, expressive character sticker based on the person in the second image, matching the art style exactly.
